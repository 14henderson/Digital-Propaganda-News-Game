# Digital-Propaganda-News-Game
A digital version of the Fake News Game (Roozenbeek & van der Linden, 2018, see https://www.tandfonline.com/doi/full/10.1080/13669877.2018.1443491). Designed to be played on mobile, and created as a supplementary activity for a talk at the Norwich Science Festival 2023. Please email n.henderson[at]uea.ac.uk for further enquiries.
